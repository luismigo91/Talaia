# Talaia

Portal personal de vigilancia meteorológica e hidrológica para **Albal** (l'Horta Sud, València) y la cuenca del **barranc del Poyo**. Agrega fuentes oficiales (AEMET, SAIH Júcar, Meteoalarm, GVA Emergències) y complementarias (Open-Meteo), las normaliza en un esquema común y permite compararlas para anticipar riesgo de inundación.
